# Production Manga & Webtoon Prompt Formulas

Use these tested prompt structures for Midjourney (v6 / Niji 6), Flux.1, and SDXL to generate authentic sequential art.

---

## 1. Classic Shonen Ink & Screentone (B&W)

```text
/imagine prompt: manga panel, [shot type: e.g. low-angle worm's-eye view medium shot], [character description + action], [expression: e.g. intense determined eyes, clenched jaw], [background environment], high-contrast Japanese manga line art, masterwork G-pen ink strokes, fine cross-hatching, traditional manga screentone dot textures, dynamic action speedlines, black and white only, sharp silhouettes, Eiichiro Oda and Kinetic Momentum and Anatomy Master aesthetic --ar 3:4 --style raw --v 6.1 --no color, 3d, realistic photograph, blurry lines
```

---

## 2. Dark Seinen / Gritty Horror (B&W)

```text
/imagine prompt: dark seinen manga panel, [shot type: e.g. dramatic extreme close-up of eyes], [character with visceral micro-expressions], heavy ink wash, dark cinematic shadows, chiaroscuro lighting, intricate cross-hatching, psychological tension, gritty atmospheric background, Baroque Inking and Physical Mass Master and Sui Ishida style, vintage ink texture on aged paper, monochrome masterwork --ar 16:9 --style raw --v 6.1 --no color, vibrant, cartoonish, smooth plastic
```

---

## 3. Modern Full-Color Webtoon / Manhwa

```text
/imagine prompt: manhwa webtoon panel, [shot type: e.g. diagonal full-body dynamic slash shot], [character description with glowing weapon/eyes], dynamic floating particles, dramatic rim lighting, vibrant saturated color grading, clean digital cel-shading, razor-sharp vector line art, glowing aura effects, high production value Solo Leveling and Tower of God style, cinematic depth of field, detailed webtoon illustration --ar 9:16 --v 6.1 --no sketch, messy lines, watermark, deformed anatomy
```

---

## 4. Shojo / Romantic Ethereal

```text
/imagine prompt: shojo manga panel, [shot type: e.g. soft focus chest-up close-up], [character description], gentle smiling expression with sparkling light reflections in oversized expressive eyes, floating cherry blossom petals, subtle screen tone gradients, delicate fine ink lines, dreamy backlighting, soft aesthetic, Io Sakisaka style, emotional atmosphere, black and white manga page --ar 4:5 --style raw --v 6.1 --no harsh shadows, gore, aggressive speedlines
```
